# Schemas

- `image-import-batch.schema.json`: kiểm cấu trúc dữ liệu LLM/OCR trích xuất từ
  ảnh trước khi Codex/Antigravity kiểm tra tổng quát độ sạch và chuyển sang
  Exam Import.

Schema chỉ kiểm cấu trúc và kiểu dữ liệu. Nó không thể xác nhận văn bản có khớp
ảnh, đáp án có bằng chứng nguồn hay hai câu có thực sự trùng nhau.
